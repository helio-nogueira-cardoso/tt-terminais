Política de privacidade

Vale para o tt-terminais (o "tt") e para o login com o Google que ele oferece. Atualizada em 16/10/2026.

O que o tt acessa

Quando a pessoa liga uma conta do Gmail ao tt, o Google pede o consentimento para o escopo https://mail.google.com/. Com ele, o cliente de e-mail que roda na máquina da própria pessoa (aerc e mbsync) lê, organiza e envia os e-mails dessa conta por IMAP e SMTP, como qualquer programa de e-mail.

Onde os dados ficam

  • O token de acesso fica num arquivo só da pessoa (permissão 600) nas máquinas onde ela instalou o tt.
  • Os e-mails, quando a pessoa liga o espelho local, ficam numa pasta da máquina dela.
  • O tt não tem servidor. Nenhum dado da conta Google vai para o autor do tt nem para terceiros. Entre as máquinas da própria pessoa, o tt troca dados por ssh (a configuração da conta e os avisos de e-mail novo, com remetente e assunto).
  • Não há anúncios, estatísticas de uso nem venda ou compartilhamento de dados.

Uso limitado

O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado. Os dados do Gmail servem só para mostrar, organizar e enviar os e-mails da própria pessoa, no computador dela.

Como revogar

Tire o acesso em myaccount.google.com/permissions e, se quiser, apague a conta no tt (menu do e-mail) e os arquivos dela em ~/.secrets e no espelho local.

Contato

Dúvidas e pedidos: issues do repositório no GitHub.

Privacy policy (English)

When a user connects a Gmail account to tt, Google asks for consent to the https://mail.google.com/ scope, used only by the mail client running on the user's own machine (aerc and mbsync) to read, organize and send that account's mail over IMAP and SMTP. The access token is stored in a private file (mode 600) on the user's own machines; mirrored mail stays in a local folder. Between the user's own machines, tt exchanges data over ssh (the account settings and new-mail notices with sender and subject). tt has no server: no Google user data is sent to the author or to third parties, and there are no ads, analytics or data sales. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Revoke access at myaccount.google.com/permissions. Contact: the GitHub issues of the repository.
